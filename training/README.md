# 仓库物资识别样本与验收边界

这里保存去除 EXIF 并缩小后的用户实拍图，以及逐物体类别和边界框标注（YOLO 格式）。类别顺序：喇叭、帐篷、手电筒、扫帚、折叠桌、指示牌、椅子、水桶、画架、麦架。原图仍由提供者保管；训练样本中的框经过人工核对，但边缘遮挡和小物体的框仍是近似标注。

训练集有 23 张单品照片和 4 张混放照片（编号 5805、5807、5809、5811）；留出的 4 张混放照片（5806、5808、5810、5812）与训练照拍摄于相同场景，**不是独立场景测试集**。模型以 Ultralytics YOLO11n 预训练权重为起点，先学习单品照，再加入混放照微调；`warehouse-specialist.onnx` 是导出的专用检测模型。线上只采纳在混放照片上有可见增益的帐篷、扫帚、指示牌候选，其他类别仍以 YOLOE-26s 文字提示或红色喇叭视觉提示为主。

2026-10-17 的人工核对：4 张留出照片合计标出 15 个目标，当前组合模型输出 7 个对应真实物资的候选框，另外 8 个仍漏检；其中折叠桌、远处喇叭和手电筒是主要缺口。这个数字来自相同场景的少量照片，只说明演示样本上的表现，不能当作泛化准确率。实时预览及正式借还识别结果均不自动改库存。

要进入自动扣库阶段，需要补拍不同房间、角度、光照和物品数量的照片，逐物体标注后划出按场景隔离的测试集，并报告漏检、误认、计数误差和误扣率。
