# 仓库物资识别样本与验收边界

这里保存去除 EXIF 并缩小后的用户实拍图，以及逐物体类别和边界框标注（YOLO 格式）。类别顺序：喇叭、帐篷、手电筒、扫帚、折叠桌、指示牌、椅子、水桶、画架、麦架。原图仍由提供者保管；部分遮挡和小物体的框是近似标注。

最终演示模型使用了全部 **23 张单品照和 8 张混放照**。`photos/train` 保存首批照片，`photos/additional` 保存后来加入训练的 4 张混放照片；两个目录都参与了最终训练，**当前没有独立测试集**。模型以 Ultralytics YOLO11n 预训练权重为起点，先学习单品照，再加入混放照微调；`warehouse-specialist.onnx` 是导出的专用模型。线上同时运行 YOLOE-26s 文字提示模型和红色喇叭视觉提示模型。

2026-10-17，在已参与训练的 8 张混放照片上，人工共标出 29 个目标，组合模型找出 28 个同类候选框（IoU≥0.3），漏掉 1 个手电筒。对原照片做调暗、轻微旋转和裁切后，主要物资仍可检出。这些只能说明**提供照片及其简单变体上的演示效果**，不能当作新环境的识别准确率，更不能据此自动扣库。

下一步要补拍不同房间、角度、光照、遮挡和数量组合的照片，逐物体标注，并按拍摄场景留出未参与训练和调参的测试集，再报告漏检、误认、计数误差和误扣率。
