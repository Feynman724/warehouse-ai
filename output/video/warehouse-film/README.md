# 物资仓库 AI 借还工作台 · 演示视频

时长约 4 分 46 秒，1920×1080，中文旁白。视频按“问题—申请—审批—同框识别—留痕—管理员复核—库存流水—训练与边界”的顺序讲述。

画面来自真实运行的产品界面；借还记录在本地隔离的演示数据库中完成，未改动线上库存。喇叭与麦架的候选框由当前服务器模型对实拍照片推理得到。视频中明确说明：8 张混放训练照片上的 28/29 是训练照回查，不是独立测试准确率；正式库存变动由管理员确认。

- `index.html`：可编辑视频工程。
- `DESIGN.md`、`SCRIPT.md`、`STORYBOARD.md`：视觉规范、旁白和分镜。
- `assets/`：产品截图、实拍图片与分段中文配音。
- `renders/warehouse-ai-demo.mp4`：本地导出的可提交视频（不纳入 Git 历史，避免仓库被大文件占满）。

本地预览：在此目录运行 `npx hyperframes preview --background`，用输出的 Studio 链接查看。可用 `npm run check` 验证工程。视频不含第三方水印。
